# Design direction

## Intent

This page uses a compact editorial style inspired by a rock gig poster: high-contrast type, direct language, and a warm paper-like background. The goal is to feel personal and experimental while remaining easy to scan on mobile and desktop.

## Choices

- **Palette:** charcoal ink on warm off-white creates a printed-page feel. Rust red is reserved for status and interaction cues.
- **Typography:** Space Grotesk supplies expressive headings; DM Mono gives the labels and navigation a technical, data-oriented voice.
- **Layout:** an oversized name introduces the page, then a one-column narrative expands into a two-column structure for each subject area.
- **Interaction:** project cards invert on hover. The treatment is deliberately small and fast so that content stays primary.
- **Responsiveness:** the layout collapses to a single column below 620 px, retaining a large, readable hierarchy.

## Content structure

1. Name and academic introduction
2. Research and personal background
3. Selected repository-backed projects
4. Rock music interest and GitHub contact link
